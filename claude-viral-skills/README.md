## 🚀 Quick Start (In 3 Minutes)

### Step 1: Open Claude or Antigravity
Open Claude Code, Claude Desktop with MCP, or Antigravity.

### Step 2: Load the Skill
Pass the skill file (e.g. `skills/html-anime.md`) or paste the master prompt from `prompts/master-prompts.md`.

### Step 3: Run the Code
Claude generates the complete vector animation (HTML/SVG or Remotion TSX component). 
Preview directly in your browser or render via:
```bash
npx remotion render <CompositionName> out/reel.mp4
```
